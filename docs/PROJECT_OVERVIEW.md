# Project overview

PipTrip is designed as a proactive personal travel assistant rather than a conventional flight-search engine.

Travelers describe the trips and travel styles they care about. PipTrip monitors relevant opportunities and helps them understand when a fare may be worth considering. The intended experience is deliberately quiet: useful opportunities should stand out, and ordinary inventory should not be presented as a deal.

## Experience principles

1. **Simple inputs** — travelers should not need to become airfare experts.
2. **Proactive discovery** — valuable opportunities should find the traveler.
3. **Honest explanations** — price freshness, uncertainty, and booking limitations should remain visible.
4. **Personal relevance** — a qualified opportunity should still fit the individual traveler.
5. **Low noise** — PipTrip should earn attention by being selective.

This document intentionally excludes implementation details, algorithms, supplier relationships, commercial terms, operational infrastructure, and private product research.
